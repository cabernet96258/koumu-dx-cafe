Excel・EXE・HTML、どれもGitHub Releases から直接ダウンロードいただけます。すべて無料・登録不要です。

7 個のツール
01 Excel · v3.2.0 成績・指導要録

テスト集計システム

単元テストの点数を入力するだけで、観点別評価から評定まで自動で出せるExcelシステムです。10教科・前後期に対応。評定への換算ラインは、教科ごとに自由に設定できます。指導要録の作成まで一続きで行えます。担当している学級の数だけダウンロードするか、コピーしてお使いください。

ダウンロード 使い方
02 HTML · v1.40.1 時間割・教科担任制

ジカンワリプロトコル

先生の情報・クラスの情報・授業のきまりごとを順番に入力していくと、ボタン一つでA週とB週の時間割案を自動で作ってくれるアプリです。パソコンにこのファイルを一つ置くだけで使えます。インターネットにつながっていなくても動きます。

ダウンロード 使い方
03 EXE · v1.0.6 汎用業務効率化

PDFパレット

Word・Excel・PowerPoint など、さまざまな形式のファイルをPDF化し、ページ番号を付けてひとつに連結します。職員会議資料の作成に。

ダウンロード 使い方
初回起動時にWindowsの警告が出た場合は、「詳細情報」→「実行」と進めばお使いいただけます。
04 EXE · v2.0.2 汎用業務効率化

フォルダツリーメーカー

新年度のフォルダ作り、去年と同じ構成を手作業で作り直していませんか。フォルダツリーメーカーは、既存フォルダの「階層だけ」を読み取り、必要なものを選ぶだけで同じ構成を作り直します。ファイルは一切コピーしないので、共有フォルダでも安心して使えます。

ダウンロード 使い方
初回起動時にWindowsの警告が出た場合は、「詳細情報」→「実行」と進めばお使いいただけます。
05 EXE · v1.2.1 汎用業務効率化

ふせんツール

思いついたときに、さっとメモ。画面の右下に常駐しているので、いつでも手軽に書き込めます。このツールの本領発揮は次年度。去年の今ごろ何をしていたか、教えてくれます。

ダウンロード 使い方
初回起動時にWindowsの警告が出た場合は、「詳細情報」→「実行」と進めばお使いいただけます。
06 EXE · v1.4.2 汎用業務効率化

スクリーンノート

マウスとキーボードの操作だけで、いま映っている画面にそのまま描き込めます。マウスポインタの位置を強調しながら、線・矢印・囲みで要点を示せます。描き込んだ画面はそのまま画像として保存できます。授業や会議、講演に。

ダウンロード 使い方
初回起動時にWindowsの警告が出た場合は、「詳細情報」→「実行」と進めばお使いいただけます。
07 HTML · v2.2.1 成績・指導要録

所見わりかん

学年・学級によって人数差がある学校では、所見を書く人数にばらつきが出てしまいます。所見わりかんを使えば、どの先生がどの学級の所見を何人書くかを簡単に計算・調整でき、記述人数を均等にできます。
