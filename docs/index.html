このサイトについて

ABOUT

「楽しく仕事ができる」ことが、
いちばんの働き方改革だと
思っています。

現職の小学校教員です。担任をしながら、放課後や休日に少しずつ道具を作っています。所属校や地域は伏せていますが、どれも目の前の職員室で本当に困ったことから生まれたものです。

辛いから効率化する、という考え方はとっていません。早く職員室を出られた日には、教材をゆっくり考えたり、子どもの話を最後まで聞けたりします。そのための時間をすこし取り戻す道具として使っていただければ十分です。

どのツールも Excel か Windows 用の EXE です。校務用端末の環境は学校ごとに違いますので、うまく動かないこともあります。使い勝手の悪いところも、正直に書くようにしています。合わなければ使わない、という判断もどうぞ遠慮なく。

不具合の報告やご要望は X のDM・リプライで受け付けています。返信はゆっくりですが、必ず読んでいます。
